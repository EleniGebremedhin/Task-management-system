# Task Management System

A task management application built with HTML, CSS, and JavaScript.

## Features

- Create, edit, and delete tasks
- Mark tasks as completed or undo completion
- Assign low, medium, or high priority
- Search tasks by title
- Filter all, pending, and completed tasks
- View total, completed, and pending task statistics
- Save tasks using browser LocalStorage
- Validate task titles and priorities
- Handle LocalStorage errors

## Technologies Used

- HTML5
- CSS3
- JavaScript ES Modules
- Browser LocalStorage

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using the Live Server extension.
4. Add and manage tasks in your browser.

Tasks are stored locally in the browser used to run the application.
